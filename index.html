Research Library Indexer

Organising a private scholarly library, and making its contents easier to find and read.

Research Library Indexer is a personal application operated by the Library of Urania account owner. It observes the owner's library in Google Drive, uses a Google Sheets Catalogue to describe holdings, and prepares search and reading data for the owner's authorised tools.

Why it connects to Google

  • Drive metadata: identifies files and tracks names, locations and changes so local observations remain connected to the correct Drive objects.
  • Google Sheets: reads and, where the owner's workflow requires it, updates the library Catalogue and related index information.

The local library workflow also reads synchronised documents, extracts text, and prepares private hosted search data. Document processing and file changes are separate operations controlled by the owner.

This website provides application information. It does not provide access to the library, display its holdings, request Google permissions, or offer public registration.

For questions about authorisation, use the support contact displayed on the application's Google consent screen.

Privacy policy

Last updated: 27 October 2026

Purpose and operator

This policy describes the personal Research Library Indexer application operated by the Library of Urania account owner. Access is intended for the owner's private research workflow.

Google data accessed and used

The application uses authorised Google Drive metadata, including file identifiers, names, locations, modification information and available checksums, to observe the library and maintain file identity. It uses authorised Google Sheets data to read and maintain bibliographic descriptions and library state.

Locally synchronised library documents and their extracted text are used to support document processing, search and reading. These functions use only the permissions and connections separately authorised by the owner.

Storage and access

Library observations, Catalogue captures, extracted text, processing records and diagnostics are stored in the owner's local environment. Derived text and search data may be transferred to the owner's hosted library service and accessed through authorised reading tools, including connected AI assistants when the owner requests their use.

Local Google OAuth credentials are protected using Windows encryption. Credentials are not included in this website. The library and its Catalogue are not made public by publishing these informational pages.

Sharing and providers

The application does not sell Google user data or use it for advertising. Data is used for the library functions described here. Google, the owner's hosting providers and any connected tools selected by the owner process data according to their applicable terms and policies.

Retention and control

Library data is retained for the owner's research and operational recovery. Revoking Google access prevents future authorised API access but does not automatically erase existing local or hosted copies. The owner controls deletion of those copies and derived records through the relevant systems.

Google access can be reviewed and revoked through Google Account connections. For questions, use the support contact shown on the Google consent screen.

This informational website

This page contains no analytics scripts, advertising, forms or application cookies. GitHub Pages hosts the website and may collect connection information, including visitors' IP addresses, for security purposes. See GitHub's privacy statement.

Changes

This policy will be updated when the application's relevant data practices change.
